# 🚀 Twitter Sentiment Analysis using Big Data

## 📌 Project Overview
This project analyzes large-scale Twitter data to classify user sentiments into **Positive, Negative, and Neutral** categories. It combines **Machine Learning, Natural Language Processing (NLP), and Big Data technologies** to process unstructured text efficiently.

The system uses **Apache Spark** for scalable data processing and an **interactive dashboard built with Streamlit** for visualization and real-time sentiment prediction.

---

## 🎯 Objectives
- Analyze public sentiment from Twitter data  
- Handle large-scale datasets using Big Data tools  
- Build an accurate sentiment classification model  
- Provide interactive visual insights through a dashboard

## ⚙️ Features
- ✅ Sentiment classification (Positive, Negative, Neutral)  
- ✅ Large-scale data processing using Spark  
- ✅ TF-IDF based feature extraction  
- ✅ Machine Learning model (Logistic Regression)  
- ✅ Interactive dashboard with charts and filters  
- ✅ Real-time sentiment prediction  
- ✅ Professional UI with analytics  

---

## 📊 Model Performance
- Accuracy: **~81%**  
- Balanced precision, recall, and F1-score across all classes

▶️ How to Run the Project
1. Clone Repository

git clone https://github.com/dipanshumilmile/Twitter-Sentiment-Analysis.git

cd Twitter-Sentiment-Analysis

2. Install Dependencies

pip install -r requirements.txt

3. Run Model

python src/sentiment_model.py

4. Run Spark Processing

python src/spark_processing.py

5. Run Dashboard

streamlit run dashboard/app.py
